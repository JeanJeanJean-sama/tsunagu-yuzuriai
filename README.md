# つなぐ ゆずりあい（試作版）

障害児の親の会「つなぐ」の会員どうしで、**余った医療ケア用品・流動食の食材・装具など**をゆずりあうための Web アプリです。
メルカリやジモティーの小さな会員向け版のようなもので、お金のやり取りはしません。

- どの品物が、**どれだけ余っているか**
- **いつ・どこで**受け渡しできるか
- 受け渡しの**相談（メッセージ）**

をひとつの場所で扱えるようにすることが目的です。

> **現在は試作版です。** データはブラウザの中（localStorage）だけに保存されるので、他の人とは共有されません。
> 画面や使い勝手を会のみんなで確かめるための段階です。共有できる本番版にする計画は [docs/BACKEND_PLAN.md](docs/BACKEND_PLAN.md) にあります。

## できること（試作版）

| 機能 | 内容 |
|---|---|
| さがす | 「ゆずります／さがしています」、カテゴリ、医療ケアの種類（胃ろう・気管切開など）、キーワードで絞り込み |
| 投稿する | 品名・数量・単位・状態（未開封など）・使用期限・地域・受け渡し方法・都合のよい日時・受付期限 |
| 相談する | 投稿者と1対1のメッセージ。「受け渡し日の提案」などの定型文つき |
| 状態の管理 | 受付中 → 相談中 → 受け渡し済み |
| マイページ | 自分の投稿と、参加している相談の一覧 |
| ルール | ゆずれるもの・ゆずれないもの、マナー（たたき台） |
| 設定 | 試作版のみ：利用者の切り替え（ゆずる側・もらう側の両方を試せる）、データの書き出し／読み込み、デモデータに戻す |

## GitHub Pages で公開する手順

ビルド作業は不要です。ファイルをそのまま置けば動きます。

1. GitHub で新しいリポジトリを作る（例：`tsunagu-yuzuriai`）。
2. このフォルダの中身をすべてアップロードする
   - ブラウザの場合：リポジトリの「Add file」→「Upload files」にフォルダの中身をドラッグ＆ドロップ
   - git の場合：
     ```bash
     git init
     git add .
     git commit -m "初回：試作版"
     git branch -M main
     git remote add origin https://github.com/<ユーザー名>/tsunagu-yuzuriai.git
     git push -u origin main
     ```
3. リポジトリの **Settings → Pages** を開き、
   - Source：**Deploy from a branch**
   - Branch：**main** / **/(root)** を選んで Save
4. 1〜2分後に `https://<ユーザー名>.github.io/tsunagu-yuzuriai/` で開けます。

> 注意：GitHub Pages の公開サイトは URL を知っていれば誰でも開けます。試作版には架空のデモデータしか入っていませんが、
> **本物の会員情報は試作版に入れないでください。** 本番版ではログインした会員だけが見られるようにします。

## 手元のパソコンで動かす

ES モジュールを使っているため、ファイルをダブルクリックで開くのではなく、簡単なサーバーを立ち上げて開きます。

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

## テスト

データ層（投稿・相談・権限チェック）の自動テストがあります。Node.js 20 以上が必要です。

```bash
npm test
```

## フォルダ構成

```
index.html              画面の外枠（ヘッダー・メニュー）
css/style.css           見た目（色は :root の変数で一括管理、ダークモード対応）
js/
  app.js                画面の切り替え（#/ で始まる URL で画面を決める）
  config.js             設定（データの保存先 local / supabase の切り替え）
  constants.js          選択肢（カテゴリ・医療ケアの種類・状態など）← 項目を変えたいときはここ
  store.js              データ層の入口（画面は必ずここを通してデータを読み書きする）
  stores/
    local-store.js      試作版のデータ層（ブラウザ内に保存）
    supabase-store.js   本番版のデータ層（ひな形・未実装）
  seed.js               デモ用の架空データ
  ui.js                 画面共通の道具（文字の安全な表示、日付の表示など）
  views/                画面ごとのファイル（一覧・詳細・投稿・相談・マイページ・ルール・設定）
tests/                  自動テスト
docs/                   設計資料・今後の計画・決めたことの記録
CLAUDE.md               AI（Claude）と一緒に開発するときの引き継ぎ書
```
